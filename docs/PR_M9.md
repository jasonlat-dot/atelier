# M9 管理后台与个人用量

本阶段把管理接口接入现有 Atelier 工作台。后端切片已推送 `bc7fc67`，最终页面与收尾检查见 PROGRESS 最新记录。当前范围到 M9；M10 未开始，S3、在线支付网关和视频尾帧协议继续待定。

## 使用入口

重启项目根目录的 `npm run dev`，API 会自动应用 `202610231100_m9_admin.sql`。仍使用已有 PostgreSQL/Redis 与本地配置文件，不需要额外服务。管理员登录并完成验证器验证后，在侧栏「运营管理」中进入：

| 页面 | 功能与权限 |
| --- | --- |
| 运营总览 `/admin` | 用户/活跃/任务/积分指标，日用量与质量分布、待复核通知、账号池健康、成本估算及已确认订单净额；ADMIN |
| 用户管理 `/admin/users` | 搜索/角色与状态筛选/分页、详情抽屉、钱包与流水、最近任务、有效设备；ADMIN |
| 任务管理 `/admin/jobs` | 搜索/状态与用户筛选/分页，取消未完成任务，补偿已结算积分；ADMIN |
| 内容与邀请 `/admin/policy` | 关键词或正则规则，以及邀请码创建、编辑、撤销；ADMIN |
| 平台设置 `/admin/settings` | 注册三态/白名单/赠送/签到/免费权益/对话参数/维护/违规阈值/调整上限/成本估价；SUPER_ADMIN |
| 审计日志 `/admin/audit` | 按操作、对象或操作者邮箱搜索，只读查看脱敏前后值；SUPER_ADMIN |
| 用量分析 `/usage` | 本人按日积分与生成任务、质量分布；所有登录用户，接口 `/api/v1/me/usage` |

既有上游账号池、模型与定价、套餐与订单、兑换码页面保留。普通管理员的导航不展示全站设置和审计；服务端同时强制权限，普通用户不能通过手工输入 URL 取得管理数据。管理员不能读取他人的对话正文、提示词或凭据。

## 用户和任务处置

- 普通管理员只能修改 USER；超级管理员可管理管理员及角色。不能禁用自己，不能禁用或降权最后一个有效超级管理员。角色或禁用状态变更立即撤销全部会话。恢复账号不恢复旧会话或已取消任务。
- 用户变更携带 revision 和必填原因；并发修改返回 409，不能覆盖后来改动。积分调整先填写增减数量和原因，再核对调整前后可用积分并确认；限额取平台设置，不能动用任务预占部分。断线后保留原幂等键与原内容，供显式重试。
- 禁用账号同事务撤销会话、取消排队生成、释放其预占，并标记运行生成取消；正在运行的任务由原有 worker 复核后停止和释放剩余预占。活动对话立即撤销运行权并释放预占，不提供后台读取正文入口。
- 人工取消已排队任务会直接取消；运行任务显示「已请求取消」，等待原 worker 处理。处置请求使用 UUID 幂等键，重复请求不重复释放。
- 「补偿积分」只允许任务结束且确实有结算，按真实 SETTLE 积分全额补偿一次。余额、补偿回执、REFUND 流水和审计同事务；审计失败全部回滚。保留任务结果与终态；补偿为独立积分来源，不恢复原订单已消费的现金可退款份额。现金退款继续在 M8 订单入口按原规则办理。

## 设置、内容与邀请

- 设置整体携带 revision，保存前列出变更项目并要求说明。只展示业务设置，不提供 OAuth、MASTER_KEY、数据库、Redis 或账号池密钥的读取/编辑入口。订阅权益在套餐中管理，免费限额在此管理。
- CLOSED 阻止普通新注册，白名单/引导管理员按原身份规则处理；OPEN 仍要求已验证的个人 Gmail；INVITE_ONLY 要求白名单或有效邀请码。已有用户正常登录不受注册模式影响。白名单保存时规范化 Gmail 地址。
- 维护模式暂停新的生成与对话请求，已提交工作继续处理，其他页面与管理入口仍可访问。素材保留期只影响新素材，不追溯更改已有素材。
- 内容规则使用最多 512 字符的关键词或有界 Rust 正则，最多 1000 条未删除规则；删除会停用并保留记录。本地和上游拒绝计入用户 30 天违规次数，默认 5 次自动禁用并产生持久待复核通知。最后一个有效超级管理员仍拒绝违规请求，但保留处理权限并提醒复核。阈值修改在下一次新增违规时判断，不批量追溯禁用。
- 总览通知链接直达用户详情；「标记已复核」只清除待复核状态，不自动启用账号。恢复账号也记录本次复核，历史违规不删除。
- 邀请码为安全随机值，数据库保存 SHA-256，完整值只在创建响应和当前弹窗显示一次；列表显示备注、末四位、次数和有效期。关闭弹窗无法再次读取完整值。撤销立即禁止后续注册，保留已注册账号和使用历史。创建结果不明时禁止直接重发：先刷新，撤销本次可能创建但无法取回的记录，再创建新码。

## 统计口径与边界

总览/个人用量支持最近 7、30、90 天（接口 1–90 天），按 UTC 自然日汇总。活跃人数按今日会话活动去重；任务量按创建日期，成功含部分完成，成功率分母排除取消及进行中；积分按账本发生日期，消费包含生成和成功对话，发放与补偿分列。

供应商真实货币账单未接入。超级管理员可以按公开模型配置 CNY/USD 单价，最多六位小数，分别以图片张数、视频秒数或成功对话条数估算；当前单价回算所选时段。没有配置的单位单独显示未估算，不能将积分当成货币或把未知价格当零。失败重试等额外费用未计入，估算不代表账单。订单金额按本期已确认到账订单及当前退款状态计算，币种分列，并非支付渠道账户余额。

审计记录不可更新、删除或清空；后台 API 对历史 JSON 再做凭据、会话、上游地址/真实模型和正文脱敏，并限制展示大小与嵌套层数。新管理写入均带前后值及原因，创建前值为 null。未接真实供应商账单、外部通知渠道、批量导出或 M10 发布合规功能。
